# Swiggy Sales & Business Analytics Dashboard 📊

A professional **Swiggy Sales & Business Analytics Dashboard** developed in Microsoft Excel to transform raw business data into meaningful, interactive insights.

This project demonstrates practical expertise in **Advanced Excel, data cleaning, data analysis, Pivot Tables, Pivot Charts, KPIs, formulas, and dashboard design**. The dashboard provides a consolidated view of business performance and enables users to analyze key sales and order-related metrics efficiently.

## 🔍 Key Analysis

- Total Revenue / Sales
- Total Orders
- Average Order Value
- Sales & Order Trends
- Category-wise Performance
- Customer & Order Analysis
- KPI Performance
- Business Performance Insights
- Interactive Filtering & Visualization

## 🛠️ Tools & Techniques

**Microsoft Excel | Advanced Excel | Pivot Tables | Pivot Charts | Excel Formulas | Data Cleaning | KPI Analysis | Data Visualization | Dashboard Development**

## 🎯 Project Objective

The objective of this project is to convert raw transactional data into a **professional, interactive business intelligence dashboard** that makes complex information easier to understand and supports data-driven analysis.

This project is part of my **Data Analytics portfolio** and showcases my ability to work with real-world datasets, identify meaningful patterns, build analytical reports, and communicate insights through effective data visualization.
